# Bitácora de avances

Historial local del proyecto del track **Clima y Territorio** (`environmental`).
Zona horaria: **America/Lima (UTC−05:00)**. Añadir entradas al final, con los hechos
verificados y los pendientes separados. Las reglas de actualización automática
durante sesiones de agentes están en [AGENTS.md](../AGENTS.md).

Registrar hitos, decisiones, pruebas, despliegues y bloqueos relevantes. Este
archivo sirve como evidencia de trabajo y como base para resúmenes; una entrada
local no significa que se haya publicado mediante `andes`.

## Formato de cada entrada

```md
## AAAA-MM-DDTHH:MM:SS-05:00 — Título del avance

[Qué cambió y qué funciona. Decisión, evidencia o bloqueo solo si aporta.
Siguiente paso concreto.]
```

Cada avance ocupa un párrafo breve de 2 a 4 frases, sin listas ni secciones.
Si se publicó en `andes`, mencionarlo únicamente tras verificarlo. Nunca registrar
claves, tokens, códigos de créditos o datos personales de usuarios.
